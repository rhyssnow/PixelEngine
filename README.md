This project has been made on a linux system, and has not been tested on other systems. Also, you will need to install sdl3, adl3_ttf, and (maybe) sdl3_image on your system before the game works -- NOTE: these are the arch linux package names, they may different on your distro --. To play the game, download the 'release' directory and run the executable located inside it.

CONTROLS:
WASD for movement
X for attack
Shift for sprint
Arrow keys to look in a direction
You can look in a direction other than the one you are moving in, but your speed will be reduced.
Space to jump
While in the air you will not take damage

The red bar is health, the green is stamina, and the purple is mana (though no mana systems have been added, so you can ignore the purple bar.

The goal of the game is to live as long as possible and kill as many wolves as you can.
