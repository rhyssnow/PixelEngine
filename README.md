Pixel engine is a custom game-engine kind of thing (though this is being designed with one project in mind rather than for creating any project) for pixel graphics using the SDL3 renderer. Last week I built a prototype to test out systems and ideas, however since it was merely a prototype, almost everything was hardcoded. I plan to eventually use this to create a larger open-world game. This week I plan to recreate the game I made last week, but with this better, more modular, and more expandable framework.

CONTROLS: WASD for movement X for attack Shift for sprint Arrow keys to look in a direction You can look in a direction other than the one you are moving in, but your speed will be reduced.

The red bar is health, the green is stamina, and the purple is mana (though no mana systems have been added, so you can ignore the purple bar.

The goal of the game is to live as long as possible and kill as many wolves as you can.
